# Knowledge Vault

A personal knowledge vault: notes, research findings and Claude's memory across projects, kept as plain Markdown files the owner controls (Obsidian-compatible), with search, a graph view of how notes connect, and a way for Claude Code sessions to read and write it so knowledge carries between sessions and projects.

**Status:** v1 (2026-10-04). Installed and in daily use: [basic-memory](https://github.com/basicmachines-co/basic-memory) as a user-level MCP server with free local hybrid search, a Claude Code hook that links, checks, commits and pushes every vault write, a skill that tells sessions when to search and write, and a private notes repo read on the iPhone with free Obsidian Git.
