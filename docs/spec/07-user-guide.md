# 7. User guide

`docs/user-guide.md` in this repo, written for the owner.

## Sections
1. What the vault is and what goes in (one paragraph, linking to the vision).
2. Install on a new PC (the install command; what it changes; how to undo it).
3. Phone setup (the procedure from `docs/spike.md`, including the two traps).
4. Everyday use: example requests ("save this to the vault", "have we seen this before?", "what do we know about X?") and what Claude does.
5. Browsing in Obsidian: folders, hubs, graph view, search.
6. Fixing things: rebuild the index; a push that failed; a note that got a secret; updating basic-memory.
7. Later: seeding other projects.

## Acceptance criteria (review checklist)
- Every command in the guide was run during Build and works as written.
- A reader can set up the phone from the guide alone (the owner confirms).
- American spelling, no em dashes, plain language.
